FAQ

Частые вопросы

Почему сайт сделан без фреймворков?

Для лабораторных работ важна прозрачная структура: обычные HTML-страницы, понятные ссылки, простая форма и JavaScript без сборки. Так легче увидеть, где именно возникает событие.

Можно ли позже подключить реальные счетчики?

Да. В каждом HTML-файле оставлены размеченные места для LiveInternet, Rambler/Top-100, Рейтинга Mail.ru, Яндекс.Метрики и информера.

Будет ли сайт работать в подпапке GitHub Pages?

Да. Все внутренние ссылки и пути к файлам относительные, поэтому проект можно публиковать по адресу вида /web-analytics-lab/.
